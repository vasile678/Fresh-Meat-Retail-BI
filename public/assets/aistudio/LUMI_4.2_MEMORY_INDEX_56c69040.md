## New-session protocol
1. Identify active project and request.
2. If connected Drive access is available, read Drive's current memory index, project registry, latest project status and relevant decisions; compare timestamps and provenance.
3. Otherwise use this packaged snapshot and disclose material freshness limits.
4. Never silently treat historical records as current.
5. At meaningful milestones, propose or write a structured update: project, date, decision, evidence, open risks, next step, links, author, validation state. Confirm successful writes.
